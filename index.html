  1. Current role2025 - today

    1. A training company’s products built as one ecosystem behind a single login: management platform, marketplace, ticketing, timesheets.

      The problem
      Separate tools, separate logins. Every new product meant another user database.
      What I did
      I designed the architecture and wrote most of the code. One authorization server issues OIDC tokens that carry identity only; each product keeps its own roles and decides who gets in.
      Under the hood
      Spring Boot 4 on Java 25, Vaadin 25 with Flow and React views, Spring Authorization Server, JPA and Flyway on MySQL, Stripe embedded checkout. Releases are git tags: the image goes to GHCR and redeploys with docker compose. Around 1,000 commits across five repositories, top committer on each.
      1. Vaadin 25
      2. Spring Boot · Java 25
      3. Authorization Server · OIDC
      4. JPA · Flyway
      5. MySQL

      • A Playwright scraper in Java, ported from a Python prototype, feeding MySQL.
      • An Electron desktop client for internal tooling.
      • Python scripts that validate Excel and PDF data for an enterprise client’s compliance process.
      • A company website in Next.js.

    1. A project management platform: a mobile app and a web app with gantt, timelines, task automations and Microsoft 365.

      The problem
      Teams planning from phone and desktop, with views that spreadsheets and chat could not give them.
      What I did

      Under the hood

      4. Firestore

  3. Personal2024 - 2026

    1. A native app for planning group trips: vote the destination, build the itinerary, split the expenses. Built twice, on purpose.

      The problem
      Group trips die in chat threads: nobody decides the destination, the expenses get lost, the plan lives in one head.
      What I did
      I was top committer on v1, built by six of us in 2025 (Angular, Ionic, Express, Prisma on Postgres). Then I wrote a technical plan and rebuilt it alone on Expo: destination voting, automatic expense settlement, itinerary on map and calendar, realtime chat.
      Under the hood
      Expo SDK 56 with expo-router and NativeWind, Zustand, Zod, react-native-maps. Cloud Functions v2 on Node 20. Firestore rules tested against the emulator, unit tests on the expense split.
      1. Expo 56 · expo-router
      2. Cloud Functions v2
      3. Firestore · tested rules
      4. Firebase europe-west1

    2. A music guessing game on printed cards: scan the QR code, the track starts on Spotify, name it before your friends do.

      The problem
      Music quizzes need a host with a playlist. I wanted a box of cards that runs the game by itself.
      What I did
      A React Native app for scanning, playback and scoring. A Python script builds the deck from Spotify and paints a radial gradient into every QR code, so it looks like a deck and not a sheet of barcodes.
      Under the hood
      Expo SDK 51, expo-camera, Zustand, NativeWind, Spotify Web API. Card generator in Python with qrcode and Pillow.
      1. Expo 51 · camera
      2. Spotify Web API
      3. Python · qrcode · Pillow
